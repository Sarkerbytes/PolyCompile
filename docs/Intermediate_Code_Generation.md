# Intermediate Code Generation — PolyCompile

---

## 1. Overview

PolyCompile uses **Three-Address Code (TAC)** as its Intermediate Representation (IR). TAC is generated by the `IRGenerator` class, which performs a post-order traversal of the unified AST and emits a linear sequence of instructions.

| Component | File |
|-----------|------|
| Header | `compiler/common/IR/IRGenerator.hpp` |
| Implementation | `compiler/common/IR/IRGenerator.cpp` |

---

## 2. What is Three-Address Code?

Three-Address Code is an intermediate representation where each instruction has at most **three operands**:

```
result = arg1 op arg2
```

This format simplifies optimization and code generation by breaking complex expressions into atomic steps. Each step uses either a source variable/literal or a freshly-generated **temporary variable** (`t0`, `t1`, `t2`, ...).

---

## 3. TACOp Instruction Set

```cpp
enum class TACOp {
    ASSIGN,                     // result = arg1
    ADD, SUB, MUL, DIV, MOD,   // result = arg1 op arg2
    CMP_EQ, CMP_NE, CMP_LT,
    CMP_GT, CMP_LE, CMP_GE,    // result = arg1 cmp arg2
    LOGICAL_AND, LOGICAL_OR,    // result = arg1 && arg2
    LOGICAL_NOT,                // result = !arg1
    LABEL,                      // result:
    GOTO,                       // goto result
    IF_FALSE_GOTO,              // ifFalse arg1 goto result
    IF_TRUE_GOTO,               // ifTrue  arg1 goto result
    PARAM,                      // param arg1
    CALL,                       // result = call arg1, arg2(count)
    RETURN,                     // return arg1
    READ,                       // read result
    PRINT                       // print arg1
};
```

### Instruction Encoding Table

| TACOp | result | arg1 | arg2 | Printed Form |
|-------|--------|------|------|-------------|
| `ASSIGN` | destination | value | — | `x = 5` |
| `ADD` | temp | left | right | `t0 = a + b` |
| `SUB` | temp | left | right | `t0 = a - b` |
| `MUL` | temp | left | right | `t0 = a * b` |
| `DIV` | temp | left | right | `t0 = a / b` |
| `MOD` | temp | left | right | `t0 = a % b` |
| `CMP_EQ` | temp | left | right | `t0 = a == b` |
| `CMP_NE` | temp | left | right | `t0 = a != b` |
| `CMP_LT` | temp | left | right | `t0 = a < b` |
| `CMP_GT` | temp | left | right | `t0 = a > b` |
| `CMP_LE` | temp | left | right | `t0 = a <= b` |
| `CMP_GE` | temp | left | right | `t0 = a >= b` |
| `LOGICAL_AND` | temp | left | right | `t0 = a && b` |
| `LOGICAL_OR` | temp | left | right | `t0 = a \|\| b` |
| `LOGICAL_NOT` | temp | operand | — | `t0 = !a` |
| `LABEL` | label | — | — | `L0:` |
| `GOTO` | label | — | — | `goto L0` |
| `IF_FALSE_GOTO` | label | cond | — | `ifFalse t0 goto L1` |
| `IF_TRUE_GOTO` | label | cond | — | `ifTrue t0 goto L0` |
| `PARAM` | — | arg | — | `param x` |
| `CALL` | retval (optional) | funcname | argcount | `t0 = call foo, 2` |
| `RETURN` | — | value | — | `return 0` |
| `READ` | variable | — | — | `read x` |
| `PRINT` | — | value | — | `print "Hello"` |

## 4. Temporary and Label Naming

```cpp
private:
    int tempCount = 0;
    int labelCount = 0;

    std::string newTemp()  { return "t" + std::to_string(tempCount++); }
    std::string newLabel() { return "L" + std::to_string(labelCount++); }
```

- Temporaries: `t0`, `t1`, `t2`, ...  — each binary or unary expression creates one
- Labels: `L0`, `L1`, `L2`, ... — used for control flow

## 5. Expression TAC Generation

### 5.1 Literal

```cpp
// LiteralNode → return its value directly (no temp needed)
case ASTNodeType::LITERAL_EXPR:
    return lit->value;   // e.g., "42", "3.14", "\"hello\""
```

### 5.2 Variable Reference

```cpp
// VarExprNode → return its name directly
case ASTNodeType::VAR_EXPR:
    return var->name;    // e.g., "x", "result"
```

### 5.3 Binary Expression

```cpp
// a + b
std::string left  = generateExpr(bin->left);   // e.g., "a"
std::string right = generateExpr(bin->right);  // e.g., "b"
std::string temp  = newTemp();                 // e.g., "t0"
instructions.push_back({TACOp::ADD, temp, left, right});
// Emits: t0 = a + b
return temp;
```

### 5.4 Unary Expression — Pre-increment

```cpp
// ++x
temp = newTemp();
instructions.push_back({TACOp::ADD, temp, operand, "1"});   // t0 = x + 1
instructions.push_back({TACOp::ASSIGN, operand, temp, ""}); // x = t0
return temp;
```

### 5.5 Unary Expression — Post-increment

```cpp
// x++
temp = newTemp();
instructions.push_back({TACOp::ASSIGN, temp, operand, ""});   // t0 = x  (old value)
std::string inc = newTemp();
instructions.push_back({TACOp::ADD, inc, operand, "1"});      // t1 = x + 1
instructions.push_back({TACOp::ASSIGN, operand, inc, ""});    // x = t1
return temp;  // expression value = old x
```

## 6. Statement TAC Generation

### 6.1 Variable Declaration with Initializer

```cpp
// int x = 5 + 3;
// → VarDeclNode with initExpr = BinaryExprNode(+, 5, 3)
std::string val = generateExpr(vd->initExpr);   // "t0" (where t0 = 5 + 3)
instructions.push_back({TACOp::ASSIGN, vd->varName, val, ""});
// Emits: t0 = 5 + 3
//        x = t0
```

### 6.2 Assignment Statement

```cpp
// x += 2
std::string val = generateExpr(ass->expr);    // "2"
std::string temp = newTemp();
instructions.push_back({TACOp::ADD, temp, ass->varName, val}); // t0 = x + 2
instructions.push_back({TACOp::ASSIGN, ass->varName, temp, ""}); // x = t0
```

### 6.3 If-Else Statement

```cpp
// if (cond) then_branch else else_branch
std::string condVal = generateExpr(condition);
std::string elseLbl = newLabel();    // L0
std::string endLbl  = newLabel();    // L1

// ifFalse condVal goto L0
instructions.push_back({TACOp::IF_FALSE_GOTO, elseLbl, condVal, ""});
generateStmt(thenBranch);
// goto L1
instructions.push_back({TACOp::GOTO, endLbl, "", ""});
// L0:
instructions.push_back({TACOp::LABEL, elseLbl, "", ""});
generateStmt(elseBranch);
// L1:
instructions.push_back({TACOp::LABEL, endLbl, "", ""});
```

### 6.4 While Loop

```cpp
// while (cond) body
std::string startLbl = newLabel();   // L0
std::string endLbl   = newLabel();   // L1

// L0:
instructions.push_back({TACOp::LABEL, startLbl, "", ""});
std::string condVal = generateExpr(condition);
// ifFalse condVal goto L1
instructions.push_back({TACOp::IF_FALSE_GOTO, endLbl, condVal, ""});
generateStmt(body, endLbl, startLbl);  // break→L1, continue→L0
// goto L0
instructions.push_back({TACOp::GOTO, startLbl, "", ""});
// L1:
instructions.push_back({TACOp::LABEL, endLbl, "", ""});
```

### 6.5 For Loop

```cpp
// for (init; cond; update) body
generateStmt(init);        // emit init code

std::string startLbl = newLabel();  // L0 — condition check
std::string incrLbl  = newLabel();  // L1 — update (continue target)
std::string endLbl   = newLabel();  // L2 — exit (break target)

// L0:
instructions.push_back({TACOp::LABEL, startLbl, "", ""});
std::string condVal = generateExpr(condition);
// ifFalse condVal goto L2
instructions.push_back({TACOp::IF_FALSE_GOTO, endLbl, condVal, ""});
generateStmt(body, endLbl, incrLbl);
// L1:
instructions.push_back({TACOp::LABEL, incrLbl, "", ""});
generateStmt(update);
// goto L0
instructions.push_back({TACOp::GOTO, startLbl, "", ""});
// L2:
instructions.push_back({TACOp::LABEL, endLbl, "", ""});
```

### 6.6 Do-While Loop

```cpp
// do body while (cond)
std::string startLbl = newLabel();  // L0 — body start
std::string condLbl  = newLabel();  // L1 — condition (continue target)
std::string endLbl   = newLabel();  // L2 — exit (break target)

// L0:
instructions.push_back({TACOp::LABEL, startLbl, "", ""});
generateStmt(body, endLbl, condLbl);
// L1:
instructions.push_back({TACOp::LABEL, condLbl, "", ""});
std::string condVal = generateExpr(condition);
// ifTrue condVal goto L0
instructions.push_back({TACOp::IF_TRUE_GOTO, startLbl, condVal, ""});
// L2:
instructions.push_back({TACOp::LABEL, endLbl, "", ""});
```

## 7. Complete TAC Example

**Source (`hello.c`):**
```c
#include <stdio.h>
int main() {
    printf("Hello World!\n");
}
```

**Generated TAC:**
```
main:
print "Hello World!\n"
return 0
```

---

**Source (`ifelse.c`):**
```c
int main() {
    int number;
    if (number % 2 == 0) {
        printf("%d is even\n", number);
    } else {
        printf("%d is odd\n", number);
    }
    return 0;
}
```

**Generated TAC (unoptimized):**
```
main:
t0 = number % 2
t1 = t0 == 0
ifFalse t1 goto L0
print "%d is even\n"
print number
goto L1
L0:
print "%d is odd\n"
print number
L1:
return 0
return 0
```

## 8. TAC Optimization Passes

After TAC generation, the `Optimizer` applies 5 passes in sequence:

### Pass 1: Constant Folding
Evaluates constant expressions at compile time:
```
t0 = 3 + 4     →    t0 = 7
t1 = 10 * 2    →    t1 = 20
```

### Pass 2: Constant Propagation
Substitutes known constant values into subsequent uses:
```
t0 = 7
t1 = t0 + 1    →    t1 = 7 + 1
```
(Then constant folding can further reduce `t1 = 8`)

### Pass 3: Copy Propagation
Eliminates redundant copy assignments:
```
t0 = x
y = t0         →    y = x
```

### Pass 4: Algebraic Simplification
Applies algebraic identities:
```
t0 = x + 0    →    t0 = x
t1 = y * 1    →    t1 = y
t2 = z * 0    →    t2 = 0
t3 = x - x    →    t3 = 0
```

### Pass 5: Dead Code Elimination
Removes temporary assignments whose result is never used:
```
t5 = x + 1     (if t5 is never referenced) → eliminated
```

## 9. Saving TAC to File

```cpp
void IRGenerator::saveToFile(const std::string& filepath) const {
    std::ofstream file(filepath);
    for (const auto& inst : instructions) {
        file << inst.toString() << "\n";
    }
}
```

Output file: `output/tac.txt` (unoptimized), `output/optimized_tac.txt` (optimized).
