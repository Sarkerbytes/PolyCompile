Architecture

6-Phase Compilation Pipeline

Every source file flows through six carefully orchestrated phases — from raw characters to executable instructions.

01
🔤
Lexical Analysis
Tokenizes source code into typed lexemes with precise line & column info
→ Token Stream
02
🌳
Syntax Analysis
Recursive-descent parser constructs a full Abstract Syntax Tree
→ AST
03
🔍
Semantic Analysis
Type checking, symbol resolution, and scope validation across all languages
→ Typed AST
04
⚡
IR Generation
Generates Three Address Code intermediate representation from the AST
→ TAC
05
🚀
Optimization
5 consecutive optimization passes eliminate dead code and fold constants
→ Optimized TAC
06
🖥
Code Generation
Translates optimized TAC into educational target assembly instructions
→ Assembly

Optimizations

      
5 Optimization Passes

      
PolyCompile performs 5 consecutive passes on the Three Address Code to produce leaner,
        faster programs.

    


    

      

        
01

        
Constant Folding

        

          

            
Before

            t1 = 5 + 3
          

          
→

          

            
After

            t1 = 8
          

        

        
Evaluates constant expressions at compile time, eliminating runtime arithmetic.

      


      

        
02

        
Constant Propagation

        

          

            
Before

            x = 10; y = x + 2
          

          
→

          

            
After

            y = 12
          

        

        
Replaces variables with their known constant values throughout the code.

      


      

        
03

        
Copy Propagation

        

          

            
Before

            x = y; z = x + 1
          

          
→

          

            
After

            z = y + 1
          

        

        
Replaces unnecessary copy assignments with their original source variables.

      


      

        
04

        
Algebraic Simplification

        

          

            
Before

            x * 1, x + 0, x * 0
          

          
→

          

            
After

            x, x, 0
          

        

        
Applies algebraic identities to simplify redundant expressions.

      


      

        
05

        
Dead Code Elimination

        

          

            
Before

            t_unused = x * 2
          

          
→

          

            
After

            // removed
          

        

        
Removes instructions whose results are never used in the program.
